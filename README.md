# Habit Auth Go (Golang) Client SDK

Official zero-dependency Golang client library for Habit Auth enterprise software protection, licensing, and microservice validation.

---

## Features

- **Standard Library Only:** Zero external dependencies for maximum compilation speed and tiny binary footprint.
- **Goroutine Heartbeat:** Telemetry runs on an isolated background goroutine with automated kill enforcement.
- **HMAC Verification:** 120-second replay attack protection with constant-time cryptographic checks.
